# Security

If you find a security problem in the iavica SDK, in the examples or in the iavica service
(iavica.com, *.iavica.app), please **report it privately by email to hello@iavica.com**.
Describe the problem and how to reproduce it.

Please do not publish anything about a vulnerability until it is fixed, and do not access, change or
delete data that is not yours while testing.

We will answer as soon as possible, tell you when it is fixed and, if you wish, credit you.
