## Use an example as the starting point of your own app

Give the file to your AI and describe what you want to change. **Ask it to give your app a new `appId`**:
the `appId` links an app to its saved data, so your app needs its own. For example:

```text
Use this file as the starting point for my own app. Give it a new appId and change it so that … .
Build my app using iavica. Follow https://iavica.com/ai to connect secure storage and publish it online.
When it's ready, explain the next steps to me with the messages from that page.
```
